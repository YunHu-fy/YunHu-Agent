## 1. 基线与结论口径

本表基于 [开发文档 v1.2](<../开发文档.md#L1-L13>)，优先落实 [第 13 行的新版本补充说明](<../开发文档.md#L13>)；同时追踪原章节中的通信、权限、工作流、可靠性及运维要求。记录日期：2026-10-19。源码已完成本轮集成冻结，本表是**实现证据与验收边界**，不是生产发布或全机型兼容认证。

- **已实现**：已阅读对应代码，存在实际调用链，不表示已经在手机上验证。
- **自动化证据**：链接到相应测试用例；除明确说明的本轮验证外，不把“存在用例”写成“本次全部通过”。完整测试数量与构建结果以最终验收输出为准，避免并行新增测试造成数字过期。
- **部分实现 / 待验收**：已有明确能力，但文档要求仍存在差异，或必须补充 APK、浏览器、真机验证。
- **扩展项 / 未实现**：不得用 API 客户端、模拟结果或占位 UI 宣称已经提供完整能力。
