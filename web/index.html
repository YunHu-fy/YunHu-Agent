关于云琥

让 AI 与你的设备协同工作。

Web v1.0

支持任意命令的后端执行器，不以工具开关限制 AI。实际能力取决于设备、所选通道、系统授权和可用运行时。

隐私与数据

会话与执行记录保存在本机。页面只连接本地桥梁；模型请求由桥梁发送至你配置且同意的服务。远程模型可能收到任务上下文、命令及其输出。API 密钥不写入浏览器持久存储；会话恢复缓存仅保留在当前标签页会话中。

关闭标签页后，完全权限的风险确认失效。请勿在非本人设备或未经授权的目标上执行自动化。

开源许可与组件

前端未使用外部 CDN 或第三方 Markdown 依赖，安全 Markdown 渲染器随应用本地加载。Termux、Python、Chaquopy、Shizuku 及其他内嵌组件的完整版权、许可证及源代码信息见安装包内第三方许可清单。

Termux：GPLv3；Python：PSF License；Shizuku API：MIT。安装包随附第三方版权与许可证文件。

欢迎使用

开始前，请了解执行边界

AI 可以通过后端执行器提出任意系统命令，可能造成数据丢失、设备异常或隐私泄露。默认采用审查模式，执行前向你展示准确命令。

Root / Shizuku 必须由系统实际授权。完全权限模式仅跳过本应用的逐次人工审查，不会突破 Android、SELinux、黑名单或超时限制。模型数据只发往你配置并同意的服务。

请先备份重要数据，仅用于合法且获得授权的任务。

将命令审查交给 AI？

完全权限开启后，新提交任务中的命令将不再逐条征求你的批准。AI 可能修改或删除文件、读取敏感数据、影响系统设置，且操作可能无法撤销。

仅影响提交时标记为完全权限的任务，执行中的任务模式不变。选择只在当前标签页会话内保存，不等于授予 Root，也不能绕过操作系统、黑名单、认证或超时。
